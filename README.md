# Bulk WhatsApp Sandor Lite

Bulk WhatsApp Sandor Lite by Pathans Apple Infotech Pvt Ltd.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/6aaceedbfb1934eef094cc78/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Bulk WhatsApp Sandor Lite** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/6aaceedbfb1934eef094cc78/releases/latest) and reinstall.
